# Документация afsyg.gay

Навигация по системе умной модерации Twitch. Прод: **https://afsyg.gay**.

> **Как это соотносится с [`AGENTS.md`](../AGENTS.md)**
> `AGENTS.md` — канонический глубокий гид: инварианты, грабли, жизненный цикл
> токенов, runbook'и. Он **источник истины** по всему хрупкому (особенно §7–§9
> про токены). Папка `docs/` — навигация «сверху вниз» и справочники, которых в
> `AGENTS.md` нет (полный API-референс, диаграмма потоков данных, операторская
> настройка). Где док касается инварианта — он ссылается на нужный § в `AGENTS.md`,
> а не переписывает его, чтобы не было расхождений.

## Оглавление

| Документ | О чём |
|---|---|
| [architecture.md](architecture.md) | Что из чего состоит, как данные текут от Twitch до дашборда, диаграмма |
| [api-reference.md](api-reference.md) | Полный REST-референс (по роутерам) + типы WebSocket-событий |
| [operations.md](operations.md) | Эксплуатация: env, деплой, ретенция, уведомления, диагностика поломок |
| [spam-detection.md](spam-detection.md) | Модель скоринга спама, пороги, сигнал подозрительности, известные пробелы |

## С чего начать

- **Разработчик, впервые в репо** → [architecture.md](architecture.md), затем
  [`AGENTS.md`](../AGENTS.md) целиком перед первым коммитом.
- **Оператор / деплой** → [operations.md](operations.md).
- **Интегрируешься с API** → [api-reference.md](api-reference.md).
- **Крутишь пороги детекта** → [spam-detection.md](spam-detection.md).
